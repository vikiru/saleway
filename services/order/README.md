# Order Service

Order processing and lifecycle management service built with [Flask](https://flask.palletsprojects.com/) and [SQLAlchemy](https://www.sqlalchemy.org/).

## Features

- Order creation, itemization, and status tracking
- Stripe checkout session correlation
- Request serialization and validation with Flask-Marshmallow
- Database migration management with Alembic

## Tech Stack

- **Framework**: [Flask](https://flask.palletsprojects.com/)
- **Language**: [Python](https://www.python.org/) 3.13
- **Database & ORM**: [PostgreSQL](https://www.postgresql.org/), [SQLAlchemy](https://www.sqlalchemy.org/), [Alembic](https://alembic.sqlalchemy.org/)
- **Serialization**: [Marshmallow](https://marshmallow.readthedocs.io/)
- **Package & Task Runner**: [uv](https://docs.astral.sh/uv/), [poethepoet](https://github.com/nat-n/poethepoet)
- **Linter & Formatter**: [Ruff](https://docs.astral.sh/ruff/)

## Setup

1. Install dependencies:

```bash
uv sync
```

2. Configure environment variables:

```bash
cp .env.sample .env
```

3. Set up the required Clerk credentials:

   - Create a [Clerk account](https://clerk.com/) and application to obtain your Clerk issuer URL for JWT verification.

4. Run database migrations:

```bash
uv run poe migrate
```

5. Start development server:

```bash
uv run poe dev
```

## Environment Variables

```bash
# Replace with your database credentials
DATABASE_URL='postgresql://order_user:<password>@localhost:5432/order_db'

# Frontend CORS
FRONTEND_URL='http://localhost:3000'

# Clerk Authentication
CLERK_ISSUER_URL='https://clerk.your-tenant.com'
```

## API Endpoints

- `GET /api/v1/health` - Health check probe
- `POST /api/v1/orders` - Create new order
- `GET /api/v1/orders/{id}` - Get order by ID
- `PUT /api/v1/orders/{id}` - Update order
- `DELETE /api/v1/orders/{id}` - Delete order
- `GET /api/v1/orders/{id}/items` - Get order items
- `POST /api/v1/orders/{id}/items` - Add item to order
- `GET /api/v1/orders/{id}/items/{item_id}` - Get order item
- `DELETE /api/v1/orders/{id}/items/{item_id}` - Delete order item
- `GET /api/v1/orders/user/{user_id}` - Get orders by user ID
- `GET /api/v1/orders/stripe-session/{session_id}` - Get order by Stripe checkout session ID

The service runs on port `5000` by default.

## Available Scripts

- `uv run poe dev` - Start development server with Flask debug mode
- `uv run poe start` - Start production server with Gunicorn
- `uv run poe migrate` - Run Alembic database migrations
- `uv run poe create-migration` - Generate autogenerated Alembic migration
- `uv run poe lint` - Lint and fix code with Ruff
- `uv run poe format` - Format code with Ruff
- `uv run poe typecheck` - Run type checks with basedpyright
